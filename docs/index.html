What to send

Field Type Limit
latitude number −90 to 90, inclusive
longitude number −180 to 180, inclusive
title string 1–80 characters after trim
message string 1–160 characters after trim
imageUrl string, optional HTTPS URL, up to 2,048 characters; no credentials

Send numbers as JSON numbers. Zero is valid. Text limits count Unicode code points. The entire UTF-8 body must be 4 KiB or smaller.

Text appears as plain text. Supply a small image that its host allows other sites to display. HandyMap loads it when someone opens the card. The image host receives that request; HandyMap does not upload, resize, or store the image.

What comes back

A successful request returns 201 Created with your ping: 

{
  "latitude": 37.7749,
  "longitude": -122.4194,
  "title": "Hello from San Francisco",
  "message": "We just shipped our first project.",
  "id": "f71a71d0-bafa-408e-b908-319d70678cf0",
  "createdAt": 1789056000000,
  "expiresAt": 1789056060000
}

Times use Unix milliseconds. The server adds id, createdAt, and expiresAt. It includes imageUrl when you supply one.

A new ping pulses for two seconds. Its dot stays for another 60 seconds. Hover, focus, or tap the dot to read its card. Refreshes do not extend that time.

One world. One shared limit.

The map accepts one ping every 1,000 milliseconds across all callers, and one ping per minute from each source address. It rejects every extra request immediately. There is no queue or automatic retry.

The initial daily limit is 10,000 accepted pings. It resets at midnight UTC. Invalid requests do not consume an acceptance slot. Live connections have a separate cap of 100 viewers. 

HTTP/1.1 429 Too Many Requests
Retry-After: 1

{
  "error": {
    "code": "rate_limited",
    "message": "The map accepts one ping per second. Try again later.",
    "retryAfterMs": 742
  }
}

On 429, wait at least the number of seconds in Retry-After. Add a small random delay before you retry. Another caller can take the next slot. Avoid retry loops; use a small retry count.

For source_limited, Retry-After counts down the minute since your last accepted ping. For daily_limit, Retry-After points to midnight UTC. A network failure does not prove rejection: the server can accept a ping before the response reaches you.

Status Meaning
400 Invalid JSON or payload
404 Unknown API endpoint
405 Wrong HTTP method
413 Body exceeds 4 KiB
415 Content type is not application/json
429 One-second, one-minute, or daily limit
503 Live service unavailable

Application errors use { "error": { "code": "…", "message": "…" } }. Cloudflare can return its own error page when its free quota runs out. The map shell and this guide remain static.

A private, temporary space

The hosted site uses the existing Cloudflare Access policy. All viewers with access share the same map. There is no archive. Other viewers can copy what they see. External image hosts still receive image requests.

The local API supports Cross-Origin Resource Sharing (CORS). The hosted Access gate redirects anonymous requests to login, including API preflight and WebSocket requests. Use the signed-in site for hosted requests. Preflight requests do not consume the shared acceptance slot.

This project runs on a free service with finite quotas. Rejected requests still use quota. The map can stop accepting pings or live connections until the quota resets.
