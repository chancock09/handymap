01 / Open atlas

Make the map the whole workspace. Keep one header and one Send action. Open the active list only when a viewer asks for it.

What changes

Remove the large introduction, API strip, repeated map captions, and outer card. Keep the API guide in the header.

Tradeoff and scope

More room for the map. The list takes an extra action to open. Medium effort; keep the existing form and list behavior.

These are design proposals, not deployed screens. Buttons open local sample content. Sample cities describe the mock data only; the app still accepts coordinates. Map geometry: Natural Earth via World Atlas.
